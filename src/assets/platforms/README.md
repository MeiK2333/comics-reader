# Platform icons

These are the real platform icons, not generic drawings. Prefer official assets
(raster or vector). When a platform only ships a tiny favicon, a pixel-accurate
SVG redraw of that favicon is acceptable; do not invent unrelated artwork.

| File | Source | Notes |
| --- | --- | --- |
| `manhuagui.svg` | <https://www.manhuagui.com/favicon.ico> | 16×16 favicon redrawn as a pixel-accurate SVG (8 colors, 60 runs) |
| `jm.png` | <https://syimg.3dmgame.com/uploadimg/ico/2026/0730/1785403601108808.jpg> | Outer white border removed and cropped to a transparent circle |
| `nhentai.svg` | <https://nhentai.net/logo.svg> | Official vector logo; its white strokes need the dark chip in `HomeView` |

Prepared on 2026-10-25. Re-download and overwrite these files if a platform
changes its branding. The icons remain the property of their respective sites
and are used only to identify the platform.
